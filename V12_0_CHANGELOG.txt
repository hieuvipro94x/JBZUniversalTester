JBZUniversalTester V12.0 - YEU CAU 3
==================================

1. CONFIG
- production.settings.json + UniversalTester.cfg are both saved.
- UniversalTester.cfg uses English key names.
- App startup normalizes and writes the complete configuration.
- Migration reads the legacy Htdrv keys [카드 수], [USB 지연], [스탬프 지연(msec)] when JSON is absent.
- Settings password is enforced when opening Settings.
- Test Pointer enable/disable is enforced.
- ItemHeight, ScrollDelay, PageDelay, ShowTitle, ShowConnector are connected to TestWindow.
- StartCardNumber is applied to board IO decoding.
- ResistanceDelayMs is applied before resistance measurements.
- R1..R5 settings can override physical measurement channel/routing; THT limits remain authoritative when present.
- AutoSaveErrors/MinimumErrorLogValue are active.

2. STAMP / RELAY
- StampDelay is two relay ON durations: Relay 1 = JIG EJECT, Relay 2 = MARKING.
- Example 10,20 => Relay1 ON 10 ms, Relay2 ON 20 ms.

3. HISTORY
- SQLite test history is saved per completed production product.
- Fields follow ALL6 sample: DateTime, 파트명, 파트번호, Eco, Nco, Alc, Lot, HtdrvName plus result/detail fields.
- HtdrvName = current program/version + Card Count + USB Delay + Stamp Delay.
- Search by date range, LOTNO, part name/number/model, result.
- Export CSV and XLSX.

4. LABEL
- PASS automatically generates/prints EPL when AutoPrintLabelOnPass is enabled.
- Data sequence follows ALL6 sample: PartNumber, Eco, PartName, yyMMdd+LOT+WH, PartNumber+yyMMdd+LOT.
- Supports COM EPL or RAW Windows printer; last EPL preview is saved to Data/Labels/last-pass.epl.

5. TEST WINDOW
- Shows live PC date/time above product information.
- Middle labels narrowed, value fields widened.
- Main status block has fixed width and smaller text.
- Relay test names changed to RELAY 1 - MỞ JIG / RELAY 2 - MARKING.

6. EXISTING V11.9 FEATURES RETAINED
- Master good/bad sample gate.
- LOTNO/statistics per model.
- Probe/Production routing.
- Fast continuous board scan/recovery.
