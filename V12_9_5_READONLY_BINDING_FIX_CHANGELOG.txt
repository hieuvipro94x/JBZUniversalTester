JBZUniversalTester V12.9.5 - READONLY BINDING FIX
================================================

1. Fixed runtime WPF InvalidOperationException:
   "A TwoWay or OneWayToSource binding cannot work on the read-only property 'PartNumber'"

2. Root cause:
   TextBox.Text defaults to TwoWay. TestWindow.xaml used implicit bindings for
   PartNumber/ProductName/VehicleType/CustomerCode/Lot while those TestViewModel
   properties are read-only or externally read-only.

3. TestWindow.xaml fixes:
   - PartNumber      -> Mode=OneWay
   - ProductName     -> Mode=OneWay
   - VehicleType     -> Mode=OneWay
   - CustomerCode    -> Mode=OneWay
   - Lot             -> Mode=OneWay
   - ToolTips for product fields explicitly OneWay.

4. ReadOnlyFieldStyle hardened:
   - IsReadOnly=True
   - IsReadOnlyCaretVisible=False
   - IsTabStop=False
   - Focusable=False

5. No fake setters added. TestViewModel read-only/computed properties remain read-only.
   Existing PropertyChanged notifications on model change were verified.

6. Project-wide binding audit:
   - No OneWayToSource found.
   - TestWindow only retains TwoWay for SelectedOperationTabIndex (writable property).
   - ProductionSettingsPage TwoWay bindings remain because their target properties are editable and have public setters.
   - Settings.LastThtPath remains OneWay.

7. Master Auto / Probe / Card / Production / bottom toolbar logic was not changed.
