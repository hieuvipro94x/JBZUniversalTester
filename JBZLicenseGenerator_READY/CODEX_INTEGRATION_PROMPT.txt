CODEX TASK - TÍCH HỢP JBZLicenseGenerator VÀO SOLUTION + JBZUniversalTester
============================================================================

BỐI CẢNH:
Đã có project độc lập JBZLicenseGenerator được tạo sẵn.
Không viết lại tool từ đầu.
Hãy đọc project đó và tích hợp phần VERIFY vào JBZUniversalTester.

MỤC TIÊU:
- License gate chạy TRƯỚC MainWindow.
- Chưa đăng ký / license không hợp lệ -> RegistrationWindow.
- Đăng ký thành công -> mới tạo MainWindow.
- Các lần sau license hợp lệ -> bỏ qua RegistrationWindow.
- Cài lại Windows / thay CPU / thay SSD hệ điều hành -> Registration ID thay đổi theo policy đã thống nhất.
- Máy mới / ID mới -> license cũ không hợp lệ.
- Hoàn toàn offline.

YÊU CẦU BẢO MẬT:
1. TUYỆT ĐỐI KHÔNG đưa PRIVATE KEY của JBZLicenseGenerator vào JBZUniversalTester.
2. App chỉ chứa PUBLIC KEY từ:
   %LOCALAPPDATA%\JBZ\LicenseGenerator\jbz-license-public.pem
   tại thời điểm tích hợp/development.
3. Public key được embed hoặc lưu như resource/read-only constant phù hợp.
4. Verify ECDSA P-256 SHA-256 với:
   DSASignatureFormat.IeeeP1363FixedFieldConcatenation.
5. Format activation code phải tương thích 100% với tool:
   JBZ1.<payload-base64url>.<signature-base64url>
6. Canonical payload phải tương thích 100%:
   JBZ1|JBZUniversalTester|MACHINE_ID|PERPETUAL|ISSUED_UNIX_SECONDS
7. Không tạo "secret" đối xứng trong app.

KIẾN TRÚC APP NÊN THÊM:
- Services/MachineFingerprintService.cs
- Services/LicenseVerificationService.cs
- Models/LicensePayload.cs hoặc shared equivalent
- Views/RegistrationWindow.xaml
- Views/RegistrationWindow.xaml.cs

STARTUP:
App.OnStartup
 -> compute Registration ID
 -> validate stored license
 -> valid: create MainWindow
 -> invalid: show RegistrationWindow first
 -> registration success: save license, then create MainWindow
 -> cancel/close without registration: Shutdown

QUAN TRỌNG:
MainWindow KHÔNG được tạo trước khi license hợp lệ.
Không được khởi tạo MainViewModel/FTDI/model/printer trước license gate.

MACHINE FINGERPRINT POLICY:
Hãy triển khai ổn định và deterministic từ:
- Windows installation identity (để cài lại Windows tạo ID mới),
- CPU identity,
- system/OS disk identity.

Phải:
- normalize dữ liệu;
- có fallback rõ khi WMI field thiếu;
- hash SHA-256;
- Registration ID hiển thị dễ đọc nhưng đủ dài, ví dụ 16 hex hoặc hơn;
- không log raw serial nhạy cảm nếu không cần.

Cài lại Windows -> Registration ID mới.
Thay CPU -> Registration ID mới.
Thay system SSD -> Registration ID mới.
Reboot/update app -> ID giữ nguyên.

REGISTRATION WINDOW:
Tiếng Việt:
ID ĐĂNG KÝ
MÃ ĐĂNG KÝ
ĐĂNG KÝ
SAO CHÉP ID

Nếu mã sai:
- ở lại RegistrationWindow;
- báo "MÃ ĐĂNG KÝ KHÔNG HỢP LỆ";
- không vào MainWindow.

Nếu mã đúng:
- lưu activation code vào app data/config phù hợp;
- verify lại ngay sau save;
- đóng RegistrationWindow;
- mở MainWindow.

KHÔNG lưu chỉ Registered=true.
Phải verify signature + Product + MachineId mỗi startup.
