JBZUniversalTester V10.2 FAST MULTICARD

- Fixed Htdrv card semantics: 64 I/O/card.
- START_SCAN now uses 8C 00 <CardCount> 00 instead of hard-coded 02.
- Auto-expands CardCount from THT MaxIo (WH322244 max > 192 => 4 cards).
- Decoder supports 80/A0 bank0 and 81/A1 bank1 up to 256 I/O.
- Supports repeated TestPin marker A0/A1 words inside a frame.
- Same normalized WireName always maps to the same continuity network.
- Keeps explicit 선연결 aliases for linked-name networks.
- D2XX scan uses one long-running reader, not Task.Run for every poll/read.
- USB idle delay follows ProductionSettings.UsbDelay; default 1 ms from trace.
- Adds FTDI 115200/8N1/no-flow/USB buffer configuration.
- TestEngine only refreshes UI when active/pass/fault state changes.
- PinProbe detects newly-active transitions rather than smallest absolute active I/O.
- No XAML layout changes.
