JBZUniversalTester V12.5.0 - VERSION / ASSEMBLY MANAGEMENT
==========================================================

Muc tieu:
- Moi lan sua source/phat hanh phai co version moi.
- File EXE cua cac version khong trung ten, tranh nham lan/ghi de.
- Version hien thi trong Windows Properties cua EXE/DLL phai dong bo.

1. Version trung tam
-------------------
Them Version.props lam SINGLE SOURCE OF TRUTH cho:
- Version / ProductVersion: 12.5.0
- AssemblyVersion:          12.5.0.0
- FileVersion:              12.5.0.0
- InformationalVersion:     12.5.0
- VersionFileTag:           12_5_0

Quy tac tu ban nay tro di:
Moi lan sua/phat hanh ban moi phai tang cac gia tri version trong Version.props.

2. Ten EXE co version
---------------------
AssemblyName duoc tao theo VersionFileTag:
JBZUniversalTester_V12_5_0.exe

RootNamespace van la JBZUniversalTester nen khong lam thay doi namespace/XAML hien co.

3. Assembly metadata
--------------------
Them Properties/AssemblyInfo.cs de danh dau chinh sach quan ly version cua assembly.
Version chinh thuc van duoc MSBuild sinh tu Version.props, tranh khai bao version trung lap.

4. Lop quan ly version trong code
---------------------------------
Them:
- Versioning/AssemblyVersionInfo.cs
- Versioning/AppVersion.cs

Code runtime doc version tu assembly that da build, khong hard-code version o giao dien.
ProgramIdentityService cung chuyen sang dung AppVersion.

5. Hien thi version tren giao dien
----------------------------------
MainWindow va TestWindow lay version truc tiep tu assembly:
UniversalTester V12.5.0 ...

6. Publish khong ghi de ban cu
-----------------------------
Scripts/Publish-OneFile.ps1 doc Version.props va publish theo thu muc:
PublishSingle/V12.5.0/

EXE:
PublishSingle/V12.5.0/JBZUniversalTester_V12_5_0.exe

Khi tao V12.6.0, output se nam trong PublishSingle/V12.6.0/ va V12.5.0 van duoc giu nguyen.

7. Quy uoc cho cac lan sua tiep theo
-----------------------------------
Vi du:
V12.5.0 -> V12.6.0 -> V12.7.0 ...

Neu can patch nho co the dung:
V12.5.0 -> V12.5.1
nhung moi goi source/EXE giao cho san xuat bat buoc phai co version duy nhat.

8. Cong cu tang version
-----------------------
Them:
- Scripts/Bump-Version.ps1
- BUMP_VERSION.cmd

Chay BUMP_VERSION.cmd khong tham so:
- Tu dong tang minor, vi du V12.5.0 -> V12.6.0.

Hoac:
BUMP_VERSION.cmd 12.5.1

de chuyen den patch cu the.
Script tu dong dong bo Version/AssemblyVersion/FileVersion/InformationalVersion/
VersionFileTag/AssemblyTitle.
