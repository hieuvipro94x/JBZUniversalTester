# Master presentation and open sample confirmation

Good, wrong-wire, short and open samples use the live production wire table during installation/testing. Collecting Master fault evidence does not replace the table with only the collected faults; the table remains live while a Master Leak sequence owns validation.

An open/loose-terminal sample is accepted only from a valid authoritative production frame covering every required THT source, without wiring fault candidates/confirmed faults or contact instability. Its live missing-connection count must exactly equal the configured required open count; all remaining expected connections must therefore be fitted. Missing faults from different frames or installations are never accumulated to satisfy the count.

An empty product, incomplete source coverage, extra missing connections, zero required count, wrong-wire/short evidence or a presentation-only SOURCE preview cannot satisfy this gate. No additional timing or firmware commands are introduced.
