# CODEX TASK — HOÀN THIỆN LỊCH SỬ KIỂM TRA + TÌM KIẾM + XUẤT CSV GIỐNG `ALL.csv`

Làm việc trực tiếp trên project `JBZUniversalTester`.

## 1. MỤC TIÊU

Phân tích và sửa hoàn chỉnh luồng:

```text
TEST
→ LƯU LỊCH SỬ
→ TÌM KIẾM LỊCH SỬ
→ HIỂN THỊ 14 CỘT TIẾNG VIỆT
→ XUẤT CSV 14 CỘT TIẾNG HÀN
```

File tham chiếu là:

```text
ALL.csv
```

Task này chỉ tập trung vào:

```text
History
History database
History search/filter
History UI
History snapshot
CSV export
```

Không sửa logic phần cứng, relay, Keysight, leak device, continuity protocol, printer protocol hoặc PASS/FAIL cốt lõi trừ khi cần đọc kết quả để lưu History.

---

# 2. PROJECT NÀY DÙNG FILE CẤU HÌNH `.tht`

Project hiện tại dùng:

```text
*.tht
```

làm file cấu hình sản phẩm.

Không sử dụng `.model` cho History của project này.

Phải trace source thật:

```text
Mở .tht
→ parse .tht
→ current product configuration
→ chạy test
→ hoàn thành cycle
→ lưu History
```

Search toàn repository trước khi sửa:

```text
.tht
Tht
ThtPath
CurrentTht
Configuration
Setup
ProductConfig
History
```

Không giả định tên class/property.

---

# 3. FILE `.tht` CHỈ XÁC ĐỊNH SẢN PHẨM / CẤU HÌNH CƠ BẢN

Không được hard-code workflow theo từng mã hàng.

Các chức năng sau do **Cài đặt phần mềm hiện tại** quyết định:

```text
TEST LEAK        ON/OFF
TEST ĐIỆN TRỞ    ON/OFF
TỰ ĐỘNG IN TEM   ON/OFF
```

Cùng một file `.tht`, người vận hành có thể bật/tắt các chức năng này khác nhau giữa hai lần chạy.

Không viết kiểu:

```text
mã này luôn leak
mã này không leak
mã này luôn in tem
mã này không in tem
```

---

# 4. WORKFLOW PHẢI THEO CÀI ĐẶT

Luồng tổng quát:

```text
LOAD .THT
   ↓
TEST THÔNG MẠCH / TEST CHÍNH
   ↓
Leak Enabled?
   ├─ YES → chạy Leak
   └─ NO  → bỏ qua
   ↓
Resistance Enabled?
   ├─ YES → chạy những R slot đang Enabled
   └─ NO  → bỏ qua toàn bộ điện trở
   ↓
XÁC ĐỊNH PASS / FAIL
   ↓
Auto Print Enabled?
   ├─ YES + đủ điều kiện → thực hiện in tem
   └─ NO hoặc không đủ điều kiện → không in
   ↓
LƯU HISTORY
```

---

# 5. HISTORY PHẢI LƯU THỰC TẾ ĐÃ CHẠY

Phải phân biệt:

```text
Configured
```

và:

```text
Executed
```

Ví dụ:

```text
AutoPrintEnabled = true
```

nhưng sản phẩm FAIL trước bước in.

Thực tế:

```text
PrintExecuted = false
```

History không được ghi đã in tem.

Tương tự:

```text
LeakEnabled = true
```

nhưng workflow dừng trước khi chạy Leak.

History không được tự sinh kết quả Leak.

---

# 6. MỘT CYCLE = MỘT DÒNG HISTORY

Một sản phẩm hoàn thành một cycle chỉ tạo **một History Record**.

Dù cycle chỉ chạy:

```text
Thông mạch
```

hay:

```text
Thông mạch + Leak + Điện trở + In tem
```

vẫn chỉ một row.

Không tạo row riêng cho từng công đoạn.

# 8. HISTORY ĐIỆN TRỞ

Task này không sửa mapping relay.

History chỉ lấy kết quả điện trở đã có từ TestEngine.

Nếu Resistance OFF:

```text
không có 저항검사
```

Nếu Resistance ON:

chỉ ghi những R thực sự đã đo.

Ví dụ:

```text
R1 PASS
R4 PASS
R7 FAIL
```

History:

```text
저항검사 R1: MIN < VALUE < MAX :PASS/R4: MIN < VALUE < MAX :PASS/R7: MIN < VALUE < MAX :FAIL
```

Không ghi Channel/Relay vật lý vào CSV.

History vẫn dùng tên test slot:

```text
R1
R4
R7
```

---

# 9. HISTORY LEAK

Nếu Leak không chạy:

```text
không có 기밀검사
```

Nếu Leak chạy, lưu đúng dữ liệu thật.

Nếu có:

```text
Min
Measured
Max
Passed
```

thì có thể format:

```text
기밀검사 MIN < VALUE < MAX :PASS/FAIL
```

Nếu project có format leak riêng thì dùng dữ liệu thật của project.

Không tự bịa số.

---

# 10. HISTORY THÔNG MẠCH

Nếu thông mạch PASS:

```text
회로검사:PASS
```

Nếu FAIL:

```text
회로검사:FAIL
```

Nếu source hiện có chi tiết:

```text

Short
Miswire
Pin
Connector
```

Không làm mất fault detail hiện đang lưu.

# 11. AUTO PRINT

`Auto Print = ON` chỉ nghĩa là workflow được phép tự in khi đủ điều kiện.

Không đồng nghĩa chắc chắn đã in.

History phải phân biệt trạng thái tương đương:

```text
AutoPrintEnabled
PrintExecuted
PrintSucceeded
BarcodeValue
```

Chỉ ghi:

```text
타각
```

khi:

```text
PrintExecuted == true
AND PrintSucceeded == true
```

Không được ghi `타각` chỉ vì Auto Print đang bật.

# 22. LEGACY TEST LOG PHẢI DYNAMIC

Không dùng template cố định.

Pseudo:

```csharp
Append("검사시작 HH:mm:ss");

if (continuity actually executed)
    AppendContinuity();

if (leak actually executed)
    AppendLeak();

if (resistance actually executed)
    AppendResistance();

if (print actually executed successfully)
    Append("타각");

Append("탈거 HH:mm:ss");
```

Không append temperature.

# 30. ENCODING CSV

Phân tích file `ALL.csv` mẫu.

```text

No BOM
Delimiter ,
```

```csharp
Encoding.RegisterProvider(CodePagesEncodingProvider.Instance);
```
