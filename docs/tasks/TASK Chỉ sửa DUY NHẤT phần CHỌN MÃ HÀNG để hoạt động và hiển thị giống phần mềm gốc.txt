==============================
THAM CHIẾU PHẦN MỀM GỐC
==============================

Phân tích Htdrv3-KETQU2000.exe cho thấy phần mềm gốc dùng native Windows/MFC file dialog:

- CFileDialog / GetOpenFileNameA
- Default extension: tht
- Initial directory: C:\Item
- Filter:

    The Files (*.tht)|*.tht|All Files (*.*)|*.*||

- Không có custom Window riêng để chọn file.
- Không tự đặt Width/Height.
- Không tự tính Left/Top.
- Không MoveWindow / SetWindowPos để ép kích thước.
- Windows tự quản lý kích thước và vị trí dialog.

Cấu hình gốc tương đương:

    CFileDialog(
        TRUE,
        "tht",
        NULL,
        0x06,
        "The Files (*.tht)|*.tht|All Files (*.*)|*.*||",
        NULL
    );

    dlg.m_ofn.lpstrInitialDir = "C:\\Item";

==============================
YÊU CẦU SỬA
==============================

1. Tìm chính xác handler/command đang được gọi khi bấm nút:

    CHỌN MÃ HÀNG

2. Chỉ sửa flow mở hộp thoại chọn file.

3. Nếu hiện tại đang dùng custom WPF Window/UserControl để duyệt file thì bỏ custom dialog đó khỏi flow CHỌN MÃ HÀNG và dùng native Windows OpenFileDialog.

4. Sử dụng:

    Microsoft.Win32.OpenFileDialog

5. Cấu hình:

    var dialog = new Microsoft.Win32.OpenFileDialog
    {
        DefaultExt = ".tht",
        Filter = "The Files (*.tht)|*.tht|All Files (*.*)|*.*",
        Multiselect = false
    };

6. Thư mục mở mặc định:

    C:\Item

Nếu tồn tại:

    dialog.InitialDirectory = @"C:\Item";

Nếu không tồn tại:
- giữ fallback hiện tại của chương trình,
hoặc
- dùng thư mục model hiện tại,
hoặc
- AppContext.BaseDirectory.

KHÔNG tạo C:\Item mới chỉ để mở dialog.

7. PHẢI gán OWNER đúng cho dialog.

Ưu tiên cửa sổ đang active:

    Window? owner = Application.Current.Windows
        .OfType<Window>()
        .FirstOrDefault(w => w.IsActive)
        ?? Application.Current.MainWindow;

Sau đó:

    bool? result = owner != null
        ? dialog.ShowDialog(owner)
        : dialog.ShowDialog();

Không tạo cửa sổ owner giả.
Không sử dụng HWND desktop làm owner.

8. Tuyệt đối KHÔNG tự chỉnh kích thước dialog:

Không được thêm hoặc giữ code kiểu:

    Width
    Height
    MinWidth
    MinHeight
    Left
    Top
    WindowStartupLocation
    SetWindowPos
    MoveWindow
    GetWindowRect
    Screen.PrimaryScreen
    WorkingArea
    monitor center calculation
    DPI scale multiplier

nếu những đoạn code đó chỉ phục vụ OpenFileDialog.

9. Không ép dialog ra giữa màn hình.

Windows phải tự bố trí dialog dựa trên owner giống native common dialog.

10. Khi người dùng bấm Cancel:

    - không thay đổi model hiện tại
    - không reset chương trình
    - không clear dữ liệu
    - không tạo lỗi
    - không gọi model loader

11. Khi người dùng chọn file:

    string selectedPath = dialog.FileName;

Sau đó PHẢI gọi lại đúng flow/load method hiện tại của project.

Ví dụ nếu project hiện đang dùng:

    LoadModel(path)

hoặc:

    OpenModel(path)

hoặc:

    SelectModelAsync(path)

thì GIỮ NGUYÊN method đó.

KHÔNG viết lại parser.
KHÔNG viết lại model loader.
KHÔNG thay đổi behavior sau khi file đã được chọn.
