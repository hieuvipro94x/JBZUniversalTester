# TASK — SỬA LOGIC IN TEM_BE THEO QUY TẮC SQDZ

Hãy sửa trực tiếp project `JBZUniversalTester-NEW`.

## MỤC TIÊU

Project có 2 loại tem:

```text
TEM_TO
TEM_BE
```

Yêu cầu bắt buộc:

* `TEM_TO`: GIỮ NGUYÊN 100% logic hiện tại.
* `TEM_BE`: sửa barcode/dữ liệu DATA5 theo quy tắc mới.
* Không được làm thay đổi output của TEM_TO.
* Không hard-code theo Part Number.
* Không sửa tọa độ, font, kích thước, barcode command EPL hoặc layout của TEM_BE.
* Dữ liệu sản phẩm phải tiếp tục lấy từ file `.tht` đang test.

# 5. QUY TẮC BARCODE TEM_BE

# 6. YEAR_CODE

Hiện chỉ có quy tắc đã được xác nhận:

```text
2026 = Q
```

Tạo mapping tập trung, ví dụ:

```csharp
private static readonly IReadOnlyDictionary<int, string> SmallLabelYearCodes =
    new Dictionary<int, string>
    {
        [2026] = "Q"
    };
```

Hoặc cấu trúc tương đương phù hợp project.

KHÔNG tự suy luận:

```text
2025 = P
2027 = R
```

Nếu gặp năm chưa có mapping, ví dụ 2027:

* TEM_BE không được in barcode giả.
* Trả lỗi rõ ràng.
* Log:

```text
LABEL_DATE_CODE_UNDEFINED
Year=2027
```

Quan trọng:

Lỗi này chỉ được ảnh hưởng TEM_BE.

TEM_TO vẫn phải hoạt động bình thường.

# 7. MONTH_CODE

Ví dụ:


```csharp

```

Không tạo:

```text
08
```

cho tháng 8.

Phải là:

```text
8
```

# 10. FORMAT LOT RIÊNG CHO TEM_BE

Hiện `LotNo` trong project là dạng số.

Đối với TEM_BE, yêu cầu barcode sử dụng LOT 4 chữ số.

Ví dụ:

```text
1    → 0001
25   → 0025
321  → 0321
7001 → 7001
```

Chỉ TEM_BE format:

```csharp
data.LotNo.ToString("D4", CultureInfo.InvariantCulture)
```

hoặc implementation tương đương.

KHÔNG thay type `LotNo` toàn project.

KHÔNG đổi:

```csharp
long LotNo
```

thành string chỉ vì yêu cầu này.

KHÔNG thay format LOT của TEM_TO.

Tức:

```text
TEM_BE → LOT_NO format D4
TEM_TO → behavior hiện tại
```

# 14. TẠO MỘT BIẾN BARCODE TEM_BE CANONICAL

Để history/duplicate guard/reprint và dữ liệu vật lý trên tem không lệch nhau, nên tạo một canonical value:

```text
SMALL_LABEL_BARCODE
```

hoặc tên phù hợp project.

Ví dụ:

```csharp
string smallLabelBarcode =
    $"{data.PartNumber},SQDZ{yearCode}{monthCode}{dayCode}{lot4}";
```

Sau đó:

```csharp
values["SMALL_LABEL_BARCODE"] = smallLabelBarcode;
```

Có thể đơn giản hóa template TEM_BE thành:

```text
{SMALL_LABEL_BARCODE}
```

NẾU và chỉ nếu cách đó không phá architecture/template hiện tại.

Nếu muốn thay đổi tối thiểu thì vẫn giữ template:

```text
{PART_NUMBER},SQDZ{YEAR_CODE}{MONTH_CODE}{DAY_CODE}{LOT_NO}
```

nhưng phải đảm bảo barcode canonical ở history cũng sử dụng cùng công thức.
