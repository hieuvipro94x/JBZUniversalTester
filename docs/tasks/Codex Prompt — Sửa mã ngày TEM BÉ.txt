# Codex Prompt — Sửa mã ngày TEM BÉ

Hãy phân tích project hiện tại và CHỈ sửa logic đọc DateTime và tạo mã ngày sản xuất cho **TEM BÉ / SmallTemplate**.

File trọng tâm:
`LabelVariableResolver.cs`

## Yêu cầu rất quan trọng

KHÔNG sửa logic TEM LỚN.

KHÔNG thay đổi:

* ThtModelParser
* logic test dây
* logic máy in
* LabelPrintService
* LabelDuplicateGuard
* cấu trúc template chung
* barcode của TEM LỚN
* PartNumber
* LotNo
* prefix `SQDZ`

Chỉ sửa phần mã hóa DATE CODE của TEM BÉ.

## Cấu trúc barcode TEM BÉ phải giữ nguyên

```text
{PART_NUMBER},SQDZ{YEAR_CODE}{MONTH_CODE}{DAY_CODE}{LOT_NO}
```

Ví dụ:

```text
BE331H6000,SQDZQ7T7002
```

Trong đó:

```text
BE331H6000 = Part Number
SQDZ       = chuỗi cố định
Q          = năm 2026
7          = tháng 7
T          = ngày 29
7002       = Lot No
```

Kết quả:

```text
Q7T = 29/07/2026
```

Công thức có thể dùng:

```csharp

    return day.ToString(CultureInfo.InvariantCulture);

```

Ngoài 1..31 phải báo lỗi.

## 4. SỬA PHẦN TẠO BARCODE TEM BÉ

Hiện tại logic kiểu:

```csharp
string yearCode = ResolveSmallLabelYearCode(data.TestedAt.Year);
string monthCode = data.TestedAt.Month.ToString(CultureInfo.InvariantCulture);
string dayCode = ResolveSmallLabelDayCode(data.TestedAt.Day);
```

Phải đổi thành logic tương đương:

```csharp
string yearCode = ResolveSmallLabelYearCode(data.TestedAt.Year);
string monthCode = ResolveSmallLabelMonthCode(data.TestedAt.Month);
string dayCode = ResolveSmallLabelDayCode(data.TestedAt.Day);
```

Sau đó vẫn ghép:

```csharp
string smallLabelBarcode =
    $"{data.PartNumber},SQDZ{yearCode}{monthCode}{dayCode}{lot}";
```

Không thay đổi format barcode này.

## 5. LOT TEM BÉ

Giữ nguyên LOT 4 chữ số:

```csharp
data.LotNo.ToString("D4", CultureInfo.InvariantCulture)
```

Ví dụ:

```text
2    -> 0002
72   -> 0072
7002 -> 7002
```

Không sửa logic này.
