# 16. PARTCNT LÀ MIRROR

SQLite authoritative.

PartCnt.txt chỉ mirror.

Flow:

DB counter changed
↓
update mirror PartCnt.txt async.

Nếu PartCnt.txt mất:
rebuild từ DB.

Không:

read PartCnt.txt mỗi cycle
→ overwrite SQLite.
