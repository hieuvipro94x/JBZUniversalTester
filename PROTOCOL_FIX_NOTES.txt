JBZUniversalTester - protocol logic corrected from test_protocol.py + jbz_io_monitor.py

Verified RX protocol:
- 80 nn = I/O address nn NORMAL
- A0 nn = I/O address nn ACTIVE
- C0 00 = end of scan frame
- nn is 0-based 00..7F; model/UI I/O is 1-based 1..128
- A1/A2/A3 are NOT interpreted as card numbers.

Verified scan startup:
1) 91 00 00 00
2) wait 350 ms
3) 90 00 00 30
4) wait 350 ms
5) 8C 00 02 00
Stop/reset: 8D 00 00 00

Logic changes:
- Stateful 2-byte stream parser, survives FT_Read splitting at any byte.
- Resynchronizes by dropping one unknown byte at a time.
- Publishes ActiveIo only after C0 00.
- Marks frame complete only if all 128 I/O addresses were received.
- TestEngine ignores incomplete frames to avoid false PASS/FAIL.
- Stable-frame counting is consecutive, not cumulative across unrelated frames.
- Pin Probe consumes complete ScanFrame directly and maps protocol address +1 to model I/O.
- XAML/UI unchanged.
